# لقطات الشاشة — Screenshots

لقطات من المنصة معدّة للاستعمال في المنشورات والعروض.

**هذه الملفات مولَّدة آليًا ولا تُحرَّر يدويًا.** لإعادة توليدها بعد أي تغيير في الواجهة:

```bash
streamlit run app.py                      # في طرفية
python scripts/capture_screenshots.py     # في أخرى
```

---

## المواصفات التقنية (للذكر في المنشور عند الحاجة)

| الخاصية | القيمة |
|---|---|
| العرض المنطقي | 1600 بكسل CSS |
| معامل الكثافة | ×2 (لقطة 3200 بكسل فعليًا) |
| الصيغة | PNG بلا فقدان |
| المتصفح | Chromium (Playwright) |
| اللغة | `ar` — التخطيط من اليمين إلى اليسار |

الكثافة المضاعفة مقصودة: لقطة بكثافة ×1 تبدو مقبولة على الشاشة و**تفقد حدّتها فور
الطباعة أو العرض بجهاز إسقاط**. وأغلب المجلات تشترط 300 نقطة في البوصة للأشكال.

وقد أُخفيت في كل اللقطات **عناصر واجهة Streamlit نفسها** (شريط الأدوات، وزر النشر،
ومؤشر الحالة)، لأنها ليست جزءًا من المنصة ولا تخدم الشكل في ورقة علمية.

## اقتراح لاختيار الأشكال

لورقة أو عرض **عن المنصة نفسها**، ثلاثة أشكال تكفي عادةً:
**03** (تغطية المقرر) ثم **06** (شكل المحتوى) ثم **07 مقابل 05** (وضع الأستاذ مقابل وضع الطالب).

ولمنشور **عن تدريس حصص الأعمال الموجّهة**: **14** ثم **13** ثم **08**.

ولعرض تقديمي: **02** و**09**، فهما الأكثر أثرًا بصريًا على شاشة العرض.

---

## ملاحظة على المحتوى الظاهر في اللقطات

مؤشرات التقدم في اللقطات تظهر **صفرًا** (0 / 72 محاضرة)، لأن الالتقاط يجري في جلسة
جديدة بلا سجل استعمال. وهذا مقصود: الشكل يعرض **المنصة** لا تقدّم مستعمل بعينه.
